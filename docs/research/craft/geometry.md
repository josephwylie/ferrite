# Geometry and layout: Claude vs Codex vs Ferrite

All values are in pt. Claude and Codex captures are 1x, so 1 px = 1 pt. Ferrite captures are 2x, so their pixel values are halved. Coordinates are written `x,y` or `x0-x1`/`y0-y1` in the source PNG's own pixels. A Ferrite "now" value gives the measured size and the code that sets it. Measurements came from colour-run and ink scans (Pillow/numpy) and were checked against zoomed crops. Radii come from the 50%-coverage point on each corner's diagonal. That method returned 15.7 for Ferrite's known `R_BUBBLE` 16 and 10.8 for its known `R_PANE` 10, so read radii as ±1.

Paths: `claude/`, `codex/` and `ferrite/` are under `docs/research/craft/`. `theme.rs` is `crates/ferrite-ui/src/theme.rs`. `pane.rs`, `rows.rs` and `rich.rs` are under `crates/ferrite-pane/src/`.

## Notes

**Vertical budget is the biggest structural gap.** At the same window height, Ferrite gives up 84pt above the transcript (title bar 46 + subject strip 38) and 30pt below it (status bar). Claude and Codex give up 44 and 0. That is 70pt of reading height lost in every thread view, plus 25pt more under the composer (65.5 vs 41). The strip earns its 38pt only when there is a second subject (a subagent or a review). With only "Main" it is a one-tab row.

**Ferrite's transcript is tighter where Claude is looser, and looser where Claude is tighter.** Tables (19 vs 37 per row), tool-group rows (18 vs 36) and the prompt → work gap (27 vs 42) are all about half of Claude's. Paragraph gaps are 18 against Claude's 11. The result reads like a terminal rendering, not an app. One fix covers most of it: the gap grammar in `rows.rs:101-117` needs a prompt-specific step (40), and `rich.rs:956` needs a paragraph gap of about 0.65 line instead of one full line.

**Tables.** Both reference apps run tables across the full column with a hairline between rows, so a table reads as a structured block. Ferrite's tables shrink to their content, so a three-column table is a narrow island at the left (ferrite/conversation-app, display x 571-843).

**Tool group.** Claude and Codex disagree. Claude puts an opened group in a hairline card of 36pt rows. Codex uses unboxed icon rows at a 25pt pitch. I recommend Claude's card: Ferrite's activity grammar already copies Claude's ("Ran 2 commands (1 failed) ▸"), and the card gives a 12-row group a visible boundary that an 18pt list lacks. The card hangs 4pt outside the text column on the left (719 vs 723), so the row text lines up 8pt inside the prose. This is deliberate, and Ferrite should copy it.

**Composer width.** Claude's composer is 36pt wider than its text column (703-1470 vs 723-1454). Codex's composer matches its column exactly. I recommend Claude's: the composer reads as a frame around the column, not a block inside it. The asymmetry (20 left, 16 right) comes from Claude's scrollbar gutter, so use 16 on both sides.

**Radii, summarised** (measured → target): bubble 16 → 10, composer 10 → 12, menus 8 → 12, approval card 7 → 10, tool card none → 10, queue card none → 10, shell/code block 7 → 8, sidebar row 7 → 6. Claude's family is 6 (rows) / 10 (cards and bubbles) / 12 (composer and floats). Ferrite's is 4/5/6/7/8/10/12/16 (theme.rs:855-878). After this change, `R_SMALL`, `R_TAB`, `R_CONTROL`, `R_BLOCK` and `R_BUBBLE` can collapse to three tokens: 6, 10 and 12.

**The model picker is twice Claude's width.** It is 520 (theme.rs:2287) against 258/254. Claude opens effort as a 318 submenu beside the model menu instead of widening the picker (claude/effort-menu: model menu x1038-1296, submenu x≈1298-1616).

**Menu bounding boxes** came from an exact float-fill colour scan. Claude's fill is `#303030`, so its boxes that touch the composer (also `#303030`) were checked by eye. The plus menu ends about 4 above the composer top (≈962), not at 1008 as the bbox suggests. Codex's plus and slash menus run the full composer width (805-1538) and stop 4pt above it.

**Codex numbers that Ferrite should not copy:** the 426 sidebar with an icon rail, the 98 two-tier composer with controls inside it, and the floating side-panel card. They are a different structure from Claude's, and Ferrite has already chosen Claude's.

**Not measured:** Codex approval (no capture), Claude code fences (none in the captures), and hover-row geometry beyond the action row (Claude's answer actions are 12pt icons at a 24 pitch, 10 below the last block: claude/tools-group-open ink y789-800, x723-802).
