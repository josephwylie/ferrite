# Components, states and copy: Claude vs Codex vs Ferrite

Lane: component structure, iconography, copy, what each surface shows or hides, and the affordances it offers. Layout, type, colour and motion values belong to other lanes. This doc gives one where a component's identity depends on it.

Coordinates: `claude/*` and `codex/*` are 1x (px = pt). `ferrite/*-app.png` are 2x: Ferrite positions below are already **halved to pt**. "Ferrite code" cites `crates/…` file:line on branch `transcript-app-style`.

## What Ferrite has that both lack (cut candidates)

Ordered by how much noise each one costs.

1. **Duplicate thread rows in the nav**: the Working / Needs you / Done sections repeat threads that the Projects tree already lists (`nav::attention_list` `nav:1604`, `ck:13365 nav_content`). Neither app does this. Cut, and let the marks carry status.
2. **Random whimsical working verbs** ("Calibrating…", "Percolating…": `ferrite-core/src/progress.rs:410`). The Claude CLI has them, but Claude Desktop shows the current step instead. They add no information, and in the live captures they sit under a row that already says what is running. Use the call's own words.
3. **"esc to interrupt"** on the working line (`pane:3065`): the stop button says it.
4. **Task meter `▬▬ 1/3` in the tab bar** (`tasks_strip` `pane:2741`): duplicates the todo card.
5. **Second bar with a single "Main" tab** (`tab_strip` `pane:2408`): only worth a row when there is more than one tab.
6. **Inline result previews on shut call rows** (`· 16:HOLD={`, `· frame p50 6.1ms`, `call_result` `text:247`) and traceback boxes under shut rows. Claude shows nothing and Codex shows only status. Keep the test verdict (`· 14 passed`): it is the one preview worth its width.
7. **Explanation lines and key-hint footers** in cards and menus ("'Always allow' allows…", `↑↓ select · 1–3 pick · esc dismiss · tab amend`, `↑↓ model · ←→ effort · ↵ apply · esc`, the `/model` head label). Neither app prints key hints in menu footers. They show shortcuts in place (`⌘↵` on the button, digits on rows).
8. **Context shown twice**: a ring in the composer footer and a meter at the Changes foot, on top of the Details section.
9. **Bottom status bar** (`1 Solo ● · 2 UI overhaul · 2 need you · 1:20 pm`): neither app has one. The clock is OS chrome. "2 need you" is the dot count again. Cut it, unless view switching has no other home.
10. **Error turn reported twice** (stamp line + failure strip).
